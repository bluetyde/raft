# Mosteller Doppler-defect benchmark: reference results

`reference.json`: the MCNP5 results of R. D. Mosteller, *ENDF/B-V, ENDF/B-VI, and ENDF/B-VII.0 Results for the Doppler-Defect Benchmark*, LA-UR-07-0922 (M&C+SNA 2007, Monterey), Tables II to IV. The report is marked "approved for public release; distribution is unlimited"; the numbers are quoted for comparison (`docs/validation/doppler-defect-protocol.md`). Transcribed from an OCR of the paper; the ENDF/B-VII.0 Doppler coefficients were recomputed from their k values.
