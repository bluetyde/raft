# SEED oracle entries for RAFT

Generated by `scripts/gen-raft-oracles.cjs` in bluetyde/seed from this repo's engine golden vectors (`schema/engine-vectors/`).
Entries in `entries/` are `seed.oracle/0.1` documents; `models/` holds the cases and the synthetic library they pin by hash.
Expected values come from the committed vectors, not from any run of the adapter. A tolerance is part of the entry's hash:
changing it needs a new `entryVersion` made by a human.

18 good entries (final power, fuel temperature and energy of each of the six vectors) and 4 bad-input entries.
Not covered: any library other than the synthetic core, burnup, xenon and iodine, reactivity feedback beyond the vectors.
